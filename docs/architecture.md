# Azure Secure Client Infrastructure

## Project Overview

This project demonstrates the design, deployment, security, monitoring, and cost optimization of a Microsoft Azure environment.

## Project Objectives

- Design a secure Azure network architecture
- Deploy Azure compute resources
- Implement network segmentation
- Apply Network Security Groups
- Implement secure inbound and outbound connectivity
- Deploy an application workload
- Implement database services
- Configure Microsoft Entra ID and Azure RBAC
- Implement monitoring and logging
- Configure cost monitoring and budget alerts
- Automate deployments using GitHub
- Document security and cost optimization decisions

## Planned Azure Services

- Azure Resource Groups
- Azure Virtual Network
- Azure Subnets
- Network Security Groups
- Azure Virtual Machines
- Azure SQL Database
- Azure Application Gateway
- Web Application Firewall
- Azure NAT Gateway
- Azure Firewall
- Azure Monitor
- Log Analytics
- Microsoft Entra ID
- Azure RBAC

## Cost Management Strategy

Every Azure resource will be reviewed for cost before deployment.

Resources will only be deployed when required by the architecture.

Cost controls will include:

- Azure Cost Management
- Budget alerts
- Right-sized resources
- Removal of unused resources
- Shutdown of lab resources when appropriate
- Cost review before deploying premium services
